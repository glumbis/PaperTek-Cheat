A bypass for the PaperTek (or a similar website) full screen and focus check.
PaperTek warns you if you exit full screen or focus out of the app and warns the teach (slang for teacher).
This JS interferes with the check and tricks the website into thinking you are always in fullscreen and on the page.
PaperTek and similar pages check if you are fullscreen in many ways this blocks all of them by 
interrupting its checks and sending fake answers to its checks.

HOW TO RUN:
1. Install Tampermonkey extension.
2. Enable user scripts (norwegian: Tillat Brukerscript) in the extension settings.
3. Click tampermonkey, click "create new script", delete the contents, paste JS script, ctrl+s
4. Enjoy <3
